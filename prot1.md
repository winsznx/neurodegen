# Concepts Worth Exploring

## 1. Conviction Markets

### Core Insight

Humans never know how much conviction an agent truly has.

An agent says:

"Buy BTC."

Cool.

How strongly?

No idea.

Instead:

The agent must allocate capital proportional to conviction.

Every decision becomes a prediction.

Every prediction becomes reputation.

---

### Product

An autonomous trader that builds a public conviction profile.

Users don't follow trades.

Users follow:

* confidence
* accuracy
* decision quality
* consistency

Over time agents become investable entities.

---

### Why Judges Remember It

Because it changes the unit of value.

Not trades.

Judgment.

---

### Startup Path

Bloomberg Terminal for AI agents.

# 2. Agent Investment Committee

This one is much stronger.

### Core Insight

One AI making decisions is boring.

Five AI arguing is interesting.

---

### Product

Each trade requires consensus.

Example:

* Macro Agent
* Sentiment Agent
* Derivatives Agent
* Risk Agent
* On-chain Agent

Each votes.

Each explains.

Each has a reputation score.

Each loses influence when wrong.

The wallet only signs after quorum.

---

### Demo

Show the trade.

Show performance.

Judges immediately understand.

### Why It Wins

Novel.
